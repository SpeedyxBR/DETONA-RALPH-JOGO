# 🎮 Detona Ralph - Jogo de Habilidade

Um jogo divertido e viciante onde você precisa clicar no Ralph antes que ele desapareça! Teste seus reflexos e veja quantos pontos consegue fazer.

## 🚀 Como Jogar

1. **Iniciar o Jogo**: Clique no botão "Iniciar Jogo"
2. **Objetivo**: Clique no quadrado onde o Ralph aparece o mais rápido possível
3. **Pontuação**: Cada acerto vale 1 ponto
4. **Vidas**: Você tem 3 vidas - cada erro perde 1 vida
5. **Tempo**: Você tem 60 segundos para fazer o máximo de pontos
6. **Dificuldade**: A velocidade aumenta a cada 10 pontos

## 🎯 Controles

- **Mouse**: Clique nos quadrados
- **Teclado**: Use as teclas 1-9 para clicar nos quadrados correspondentes
- **Botões**:
  - "Iniciar Jogo" - Começa uma nova partida
  - "Reiniciar" - Reseta o jogo
  - "Jogar Novamente" - Aparece no final do jogo

## 🚀 Como Executar

1. Clone ou baixe o repositório
2. Abra o arquivo `index.html` em qualquer navegador moderno
3. Divirta-se jogando!

## 🎮 Dicas para Jogar

- **Foque nos quadrados**: Mantenha os olhos na grade para reagir rapidamente
- **Use o teclado**: Pode ser mais rápido que o mouse em alguns casos
- **Pratique**: Quanto mais você joga, melhor fica!
- **Atenção ao tempo**: O jogo fica mais rápido conforme você pontua
